How to Use

Run the Python program.

Find the distance_mi variable and enter how many miles you need to travel.

Set is_raining to True or False depending on the weather.

Set has_bike to True or False depending on whether you have a bicycle.

Set has_car to True or False depending on whether you have a car.

Set has_ride_share_app to True or False depending on whether you have a ride share app.

Run the program to see whether commuting is possible.

Example:

distance_mi = 3

This means the travel distance is 3 miles.

The program will print True if commuting is possible or False if commuting is not possible based on the conditions entered.
